# 전체 UI 정리

기존 녹색 계열과 기능을 유지하면서 검색과 주요 작업이 먼저 보이도록 정리했습니다.

## 변경한 화면

- 홈: 큰 장식 영역과 펼쳐진 이용 설명을 줄이고, 검색 카드·대표 물건 예시·기록/게임/지역 설정 바로가기로 구성했습니다. 이용 방법은 펼쳐 볼 수 있습니다.
- 마이페이지: 로그인 계정, 닉네임, 배출 지역, 저장 버튼을 한 카드 안에 정리했습니다. 실제 회원 정보를 변경하지 않고 가상 회원으로 화면을 검토했습니다.
- 로그인·회원가입: 카드 너비, 입력창, Google 버튼, 구분선과 보조 안내를 통일했습니다. 긴 비밀번호 확인 예시를 짧게 바꿨습니다.
- 물건 입력·결과: 기존 질문과 자동 입력을 유지하며 버튼·카드·재질 요약의 시각적 스타일을 맞췄습니다.
- 기록·통계: 통계 설명을 간결하게 표시하고 상세 기준은 접힌 안내에 유지했습니다. 기록은 한 줄에 하나씩 읽을 수 있도록 정리했습니다.
- 게임·랭킹: 카드·제목·버튼·표 스타일을 맞추고 시작 안내의 여백을 줄였습니다. 출제와 채점 방식은 변경하지 않았습니다.
- 공통: 화면별 제목·여백·테두리·입력창·버튼을 정리하고, 모바일 입력 글자는 16px로 표시합니다. 키보드로 사용하는 버튼·링크·입력창의 초점 표시는 유지합니다.

## 변경 파일

- `index.html`: 공통 정리 스타일 연결
- `src/styles/polish.css`: 공통 및 화면별 스타일
- `src/layouts/layout.js`: 화면별 스타일 적용용 클래스
- `src/pages/main/main.js`: 홈 구성
- `src/pages/profile/profile.js`: 마이페이지 구성
- `src/pages/signup/signup.js`: 입력 예시 문구
- `src/pages/history/history.js`: 통계 설명 표시

## 확인 결과

- 기존 자동 테스트 99개 통과를 확인했습니다.
- PC에서 홈·로그인·물건 입력·판별 결과·기록/통계·게임·예시 회원 마이페이지를 검토했습니다.
- 390px 모바일 폭에서 홈·로그인·회원가입·물건 입력·기록·게임·비회원 마이페이지의 가로 넘침이 없는 것을 확인했습니다. 예시 회원의 지역 설정 폼도 모바일로 검토했습니다.
- 홈의 생수병 예시 선택 → 조건 입력 → 판별 결과 → 비회원 기록·통계에 1개 반영되는 흐름을 확인했습니다.
- 운영 계정의 실제 회원가입·로그인·프로필 저장은 수행하지 않았습니다. 인증·데이터 저장 방식과 DB 구조는 변경하지 않았습니다.
- 마이페이지 이미지의 `student@example.com`은 화면 검토용 예시 데이터입니다. 임시 미리보기 페이지는 제거했습니다.
- 배포는 GitHub `main`과 연결된 Vercel 프로젝트를 사용하며, 배포 후 운영 스타일과 화면 코드의 반영 여부를 확인합니다.

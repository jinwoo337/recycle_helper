# 다음 분리배출 판별 개선

2026-11-14 · 판별 규칙 `2026-11-14.v20`

버리기 직전에 찾는 사용자가 배출처와 첫 행동을 빠르게 확인하도록 판별 알고리즘과 입력·결과 화면을 우선 개선한다.

## 이번에 반영한 항목

- 결과에서 ‘지금 할 일’ 다음에 이유를 표시한다. 이름·설명·사진 결과, 저장된 결과, 복사 문구에서 같은 판정의 이유를 사용한다.
- ‘다른 지역은 어떨까?’에는 배출 방법이 다른 확인 지역과 그 방법을 표시한다. 확인한 지역들의 방법이 같으면 동일하다고 표시하고, 비교할 자료가 부족하면 확인 범위를 알려 준다.
- 결과 화면에서 지역만 바꿔 재판별할 수 있다. 추가로 확인할 조건이 있으면 해당 질문으로 돌아가며 기존 답변은 유지한다.
- 전구, 물티슈, 컵라면 용기, 생수병 뚜껑, 즉석밥 그릇, 샴푸 펌프, 고기 포장의 흡수패드에 대한 후보와 안내를 보완했다. 설명이나 사진에서 확인한 내용은 해당 부위에 반영한다.
- 수거처가 필요한 결과에서 공식 배출 장소 지도로 이동할 수 있다. 현재 위치와 실제 수거함을 사이트 안에 바로 표시하는 작업은 아래 목록에 남겼다.

## 다음에 작업할 순서

| 순서 | 개선할 사항 | 완료 기준 |
| --- | --- | --- |
| 1 | 자주 쓰는 미등록 표현과 이름 검색어를 검토한다. 포장 전체와 부품을 혼동하는 표현부터 추가한다. ‘컵라면 뚜껑’, ‘컵밥 껍데기’, ‘생수병 비닐’ 등에서 본체·라벨·뚜껑을 나눠 확인한다. | 짧은 이름에서도 실제로 버리려는 부분이 후보 앞에 나온다. 오타나 유사 품목은 선택 전까지 배출 방법을 확정하지 않는다. |
| 2 | 상태 입력에서 결론을 바꾸는 질문을 먼저 보여 준다. 음식물이 남았는지, 지워지지 않는 자국인지, 라벨이나 캡을 분리할 수 있는지에 따라 질문 순서를 조정한다. | 상태 하나를 수정해도 나머지 답은 유지된다. 답이 ‘모르겠어요’인 경우 결과 화면에서 확인할 한 가지를 먼저 보여 준다. |
| 3 | 여러 부속품의 확인 결과를 한눈에 읽도록 정리한다. 본체는 확정됐고 라벨·펌프가 남은 경우, 바로 처리할 부분과 추가로 확인할 부분을 구분해서 표시한다. | ‘라벨 재질 확인’으로 이동하면 해당 항목이 열리고, 확인이 끝난 본체와 다른 부속품의 답은 다시 묻지 않는다. |
| 4 | 품목별 공식 지역 자료를 보강한다. 젤 아이스팩·종이팩·깨진 유리·오염 비닐처럼 배출처나 준비물이 달라지는 사례를 우선한다. 자료에 게시일 또는 시행일과 관할 범위를 함께 남긴다. | 같은 방식은 한 번만 표시한다. 시행일이 지난 수거 사업과 지역별 예외가 비교 화면이나 결과 이유에 잘못 섞이지 않는다. |
| 5 | 설명·사진에서 여러 표시나 부품이 확인됐을 때 원하는 항목을 고쳐 적용할 수 있게 한다. 본체와 부속품 이름, 부위별 재질·상태, 이미 선택한 답변을 기준으로 연결한다. | ‘본체 무색페트, 뚜껑 PP, 라벨 비닐’에서 확인한 정보만 적용하고, 서로 다른 뚜껑·라벨에 값이 섞이지 않는다. |
| 6 | 실제 수거함의 위치를 사이트 안에 표시할 수 있는 데이터와 지도 방식을 확인한다. 위치 권한이 없으면 선택한 지역에서 찾고, 운영시간과 접수 품목의 확인 경로를 함께 제공한다. | 검색 결과가 수거함과 후보 시설을 구분하고, 확인 가능한 수거함을 현재 위치 가까운 순서로 표시한다. |

## 다시 확인할 대표 사례

- 영수증 → 감열지 또는 일반 인쇄용지 → 다른 배출 방법과 이유
- 우유팩 → 깨끗하고 붙은 재질 없음 → 종이팩 수거와 지역별 차이
- 생수병 → 본체는 깨끗하고 라벨 상태는 모름 → 본체 안내와 라벨 질문으로 바로 이동
- 과자봉지 → 기름 자국만 남음 → 강남구와 도봉구의 안내 차이
- 젤 아이스팩 → 서초구·도봉구·경기 광주시 → 종량제봉투·특수종량제 마대·전용 수거함
- 미등록 포장재 → 설명·사진의 재질 표시를 확인 → 동일한 조건이면 동일한 배출 방법과 이유

# 다음 분리배출 판별 개선

2026-11-14 · 판별 규칙 `2026-11-14.v28`

버리기 직전에 찾는 사용자가 배출처와 첫 행동을 빠르게 확인하도록 판별 알고리즘과 입력·결과 화면을 우선 개선한다.

## 이번에 반영한 항목

- 결과에서 ‘지금 할 일’ 다음에 이유를 표시한다. 이름·설명·사진 결과, 저장된 결과, 복사 문구에서 같은 판정의 이유를 사용한다.
- ‘다른 지역은 어떨까?’에는 배출 방법이 다른 확인 지역과 그 방법을 표시한다. 확인한 지역들의 방법이 같으면 동일하다고 표시하고, 비교할 자료가 부족하면 확인 범위를 알려 준다.
- 결과 화면에서 지역만 바꿔 재판별할 수 있다. 추가로 확인할 조건이 있으면 해당 질문으로 돌아가며 기존 답변은 유지한다.
- 전구, 물티슈, 컵라면 용기, 생수병 뚜껑, 즉석밥 그릇, 샴푸 펌프, 고기 포장의 흡수패드에 대한 후보와 안내를 보완했다. 설명이나 사진에서 확인한 내용은 해당 부위에 반영한다.
- ‘컵라면 뚜껑’, ‘컵밥 껍데기’, ‘생수병 비닐’은 버릴 부분의 후보부터 보여 준다. 실제로 맞는 후보를 고른 뒤 판별한다.
- 서울 비닐은 다른 재질과 분리할 수 있는지와 남은 것이 자국인지 고형물인지 확인한다. 상태가 미확인이면 먼저 확인할 질문을 결과에서 바로 열 수 있다. 분리 가능한 부속품은 결과에서 배출 방법을 확인한 부분과 추가 확인이 필요한 부분을 따로 보여 준다.
- 설명에서 본체·뚜껑·라벨·필름에 적힌 표시를 각각 읽고, 사진은 여러 표시의 부위와 형태를 고쳐 필요한 것만 적용할 수 있다. ‘안쪽 마개’, ‘바깥 뚜껑’처럼 이름을 구분하면 같은 종류의 부속품도 각각 반영한다.
- 사진의 PET 표시는 병·단단한 용기와 얇은 필름을 구분해 확인한다. ‘비닐류 PET’처럼 분리배출 종류가 함께 적혀 있으면 비닐류로 연결한다.
- 서초구·부평구·용인시의 젤 아이스팩 종량제봉투 안내를 시행일 기준으로 적용하고 같은 방식은 한 번만 표시한다. 도봉구 종이팩, 강동구 깨진 유리, 경기 광주시 오염 비닐의 공식 안내를 추가했다.
- 경기 광주시는 젤 아이스팩이 깨끗하고 터지지 않았는지 먼저 확인한다. 전용 수거 대상이면 시청의 수거함 목록과 현재 시설 주소가 일치하는 행정복지센터 13곳을 표시한다. 주소가 달라진 3곳과 지도 좌표를 확인하지 못한 마트는 목록에서 제외했다. 지도는 시설 위치를 표시하며 현재 위치를 허용하면 직선거리 순으로 정렬한다.
- 구리시 폐의약품은 공식 공공데이터에 시설 좌표와 연락처가 있는 공공 수거함 3곳을 표시한다. 참여 약국 목록은 보건소 안내에서 확인할 수 있다.
- 성남시 폐의약품은 알약·가루약과 물약·연고의 포장 준비를 구분한다. 시청 자료에서 주소와 좌표를 대조한 분당구 행정복지센터 4곳을 지도에 표시한다.
- 장난감은 작동 방식·재질·크기를 확인해 작은 비전동 플라스틱 완구, 전동 완구, 봉제인형과 대형 완구를 구분한다. [2026-01-01 시행 기후에너지환경부 지침 별표 1](https://www.law.go.kr/flDownload.do?bylClsCd=200201&flSeq=160907851)

## 다음에 작업할 순서

1. 실제 수거함의 좌표와 데이터 기준일을 함께 제공하는 지자체부터 품목과 지역을 넓힌다. 시설명·주소가 달라진 항목은 지자체 자료에서 확인한다.
2. 짧은 검색어의 오타와 포장 부위 표현을 실제 사용 사례로 보강한다.

## 다시 확인할 대표 사례

- 영수증 → 감열지 또는 일반 인쇄용지 → 다른 배출 방법과 이유
- 우유팩 → 깨끗하고 붙은 재질 없음 → 종이팩 수거와 지역별 차이
- 생수병 → 본체는 깨끗하고 라벨 상태는 모름 → 본체 안내와 라벨 질문으로 바로 이동
- 과자봉지 → 기름 자국만 남음 → 강남구와 도봉구의 안내 차이
- 젤 아이스팩 → 서초구·도봉구·경기 광주시 → 종량제봉투·특수종량제 마대·전용 수거함
- 미등록 포장재 → 설명·사진의 재질 표시를 확인 → 동일한 조건이면 동일한 배출 방법과 이유

# 분리배출 흐름 점검 · 2026-11-11

기준 코드는 `3893bb6`이며, 운영 사이트 확인과 변경 후 로컬 브라우저 확인을 구분했다. 기존 테스트 222개가 통과하는 상태에서 시작했다.

## 재현과 수정

1. **깨진 유리의 잘못된 지역 안내.** 운영의 설명 모드에서 대전 유성구를 적용한 상태로 깨진 식품 유리병을 설명하니 실제 Gemini가 지역 기준 확인 없이 종량제봉투 배출을 안내했다. 당시 코드는 전용 수거품만 등록 기준으로 바꿨다. 이제 등록 품목은 전용 수거 여부와 관계없이 판별 규칙을 사용한다. 조건이 필요한 투명 생수병·전지·의류는 물건을 확인한 뒤 상태 질문으로 이어진다. 후보 선택과 직접 정정을 추가했다. 답을 모르거나 필요한 질문이 남아 있으면 생성된 배출 절차는 표시하지 않는다.
2. **전지와 포장 혼동.** 운영의 ‘건전지 포장’에는 정확한 포장 후보가 없었다. 전지라는 낱말 때문에 일반 포장재 결과에 전지 수거처가 붙을 수 있었다. 빈 포장만 판별한다는 안내와 정확한 후보를 추가하고, 포장은 재질·상태로 판별한다. 정상·손상 전지 안내와 분리했다. 미등록 이름에 대한 AI 추정만으로 종량제 배출을 확정하지 않는다.
3. **사진에서 설명으로 갈 때의 막힘.** 사진 모드에서 설명 초안이 남아 있어도 뒤로 돌아오면 사진을 잃었다. 같은 검색의 사진·설명 초안은 탭 메모리에 유지하고, 사진 분석이 실패하면 같은 사진으로 다시 시도하거나 설명으로 넘어갈 수 있다. 다른 물건에서 이전 사진을 불러오지 않도록 검색 전환을 구분한다.
4. **부속품과 다음 행동.** 라벨·뚜껑의 이름을 상태 질문에 표시한다. 조건 수정은 확인할 본체나 부속품 질문을 먼저 찾아간다. 결과와 복사에서 공유하는 준비 단계는 한 번만 표시한다. 복사에는 전지·의류에서 고른 상태와 확인된 대형폐기물 신청 주소도 포함한다.
5. **철제 책상.** 재질만으로 캔류 수거를 안내하지 않는다. 전국 기본 안내는 실측과 부속 가구 확인을 요청한다. 유성구는 실제 품목표에 따라 서랍 형태, 컴퓨터용, 세트 여부를 먼저 확인하도록 바꾸고 공식 신청과 품목표 버튼을 배치했다. 지역별 차이가 큰 추정 수수료 범위를 제거했다.

## 11월 12일 후속 개선

- 이름 추천에 입력한 이름, 등록된 다른 표기, 비슷한 이름을 구분해 표시했다. 띄어쓰기나 전각 영문이 섞여도 같은 표기를 먼저 보여 준다. 건전지와 빈 포장, 유리병과 깨진 유리병, PET병 별칭으로 검색 동작을 확인했다.
- 이름 결과와 설명·사진의 등록 품목 결과에서 배출 순서를 체크할 수 있다. 본체와 부속품 단계를 각각 확인한다. 진행 상태는 열린 결과에만 유지된다. 생수병과 라벨 결과에서 체크, 초기화, 다시 열기를 모의 DOM 이벤트로 검증했다.
- 이전 기록의 배출 방법을 목록, 상세, 복사, 제보에서 현재 규칙으로 맞췄다. 통계와 유형 필터는 저장 당시 기준이라고 표시했다. 복사한 안내에는 본체와 부속품의 상태도 포함된다. 이전 버전 결과 첨부와 복사 조건을 회귀 테스트로 확인했다.
- 수거처 카드의 지도는 판별 지역으로 바로 열 수 있다. 선택적으로 위치를 적용할 수 있으며, 결과에 표시된 지역은 그대로 유지된다. 시설 이름으로 검색하고 실제 접수 여부와 운영시간을 확인하도록 안내한다. 손상 전지의 경우 문의할 곳을 표시한다. 정상·손상 전지의 카드 문구와 기본 지도 주소를 자동 테스트로 확인했다.
- 결과 카드와 모바일 메뉴의 여백, 버튼 크기, 단계 간 구분을 조정했다. 로컬 미리보기 주소의 접근 권한이 거절되어 이 변경의 화면 렌더링과 위치 권한 동작은 직접 확인하지 못했다. 후속 변경은 운영에 배포하지 않았다.

## 나무젓가락과 미등록 품목

- 나무젓가락, 일회용 나무젓가락, 목재·대나무 젓가락을 등록했다. 추가 상태 질문 없이 일반 종량제봉투 배출을 안내한다. 음식물과 겉포장을 분리하고, 함께 사용한 플라스틱 숟가락이나 배달 용기는 짧은 요령과 별도 판별 버튼으로 확인한다. 숟가락과 용기의 재질 및 지역 수거 조건이 다를 수 있어 관련 물건에 같은 배출 방법을 적용하지 않는다. [환경부 재활용품 분리배출 가이드라인](https://clean.yongsan.go.kr/resources/images/user/recycleExhaust.pdf), [노원구 생활폐기물 배출 안내](https://www.nowon.kr/www/minwon/minwon4/minwon4_03/minwon4_03_02.jsp)
- 미등록 품목의 전체 종류 드롭다운을 제거했다. AI 자동 제안이 꺼져 있어도 버튼으로 한 번만 요청할 수 있다. 제안이 나오면 물건 종류와 필요한 재질을 확인하고 해당 상태 질문으로 이어진다. AI가 이름으로 판단하기 어려우면 용도·표시 설명, 포장재 표시, 음식물, 재질만 확인, 수거 기준 확인 방법으로 이어진다. 재질만 선택했거나 AI가 확신하지 못한 경우에는 배출 경로를 확정하지 않는다.
- 자동 테스트에서 젓가락 별칭, 금속 젓가락과의 구분, 관련 물건 버튼, AI의 모의 제안과 사용자 확인 조건, 재질만 아는 경우의 안내를 검증했다. 이번 AI 분류 형식과 화면은 운영에 배포하지 않았다. 실제 Gemini 응답과 휴대폰 화면은 이번 변경의 검증 범위에 포함되지 않았다.

## 입력 방식과 상태 확인

- 홈과 이름·설명·사진 화면에 같은 찾기 방식 메뉴를 배치했다. 이름에서 설명이나 사진으로 넘어갈 때 판별 지역도 이어진다. 홈으로 돌아오면 직전 이름을 복원한다.
- 설명·사진에서 전지나 의류를 인식하면 그 화면에서 상태를 선택해 등록 기준을 확인한다. 상태 선택에는 AI 재요청이 필요 없다. 다른 방식으로 이동했다 돌아왔을 때 설명·사진·지역이 같으면 분석 결과와 작성 중인 답변을 복원한다. 지역이나 입력이 달라지면 새 기준으로 확인할 수 있게 기존 결과를 숨긴다.
- 본체 상태를 부속품에 적용할 때 종이의 오염 부분을 떼는 질문과 물로 헹구는 질문 사이에 답을 복사하지 않는다. 현재 오염 상태를 바꾸면 이전 오염 제거 답도 비운다.
- 파일 종류 정보가 비어 있는 JPG·PNG·WebP도 파일 이름과 실제 디코딩으로 확인한다. HEIC 변환기를 불러오지 못하면 재시도할 수 있다. 실제 스마트폰에서 HEIC 디코딩과 카메라 입력을 확인하는 일은 남아 있다.

## 조건 확인과 관련 식기

- 추가 확인이 필요한 결과에는 확인할 질문을 상단에 표시했다. 예를 들어 라벨의 오염 여부를 모르면 본체 상태가 아닌 라벨 질문으로 돌아간다. 저장 기록에서도 같은 질문으로 이동한다.
- 설명·사진의 등록 품목 결과를 지역·조건·출처와 함께 복사할 수 있다. 결과 오류 제보에서는 문제가 있는 부분을 선택하고 짧게 설명할 수 있다. 화면의 물건 이름·지역·안내는 함께 첨부된다. 모의 클립보드 권한 실패와 늦은 응답, 제보 전송 중 중복 방지를 확인했다.
- 일회용 숟가락은 나무와 플라스틱 중 실제 재질을 고른다. 목재는 종량제, 단일 플라스틱은 오염 제거 및 지역의 소형 플라스틱 수거 확인을 안내한다. 일반 플라스틱 용기의 지역 지침을 숟가락에 적용하지 않는다. [분리의정석 단일 재질 숟가락](https://wasteguide.or.kr/front/dischargeMethod/dictionaryView.do?niIdx=601), [작은 플라스틱 숟가락](https://wasteguide.or.kr/front/dischargeMethod/dictionaryView.do?niIdx=416), [목재 등 숟가락](https://wasteguide.or.kr/front/dischargeMethod/dictionaryView.do?niIdx=775)
- 사진·설명 결과에서 이름을 고칠 때 자동완성을 제공한다. 한글 조합을 확정하는 Enter에서 제출이 일어나지 않는지 모의 이벤트로 검증했다.
- 지역 비교는 달라지는 안내를 먼저 보여 주고, 모든 비교 결과에 공통인 단계는 한 번만 표시한다. 결과를 기록에서 다시 열어도 ‘지역 변경’으로 바로 갈 수 있고, 저장한 물건과 조건이 입력 화면에 이어진다.
- 기존 DB 카탈로그에서 플라스틱 숟가락이 포크·나이프와 묶여 있어도 앱은 검토한 숟가락 기준을 사용한다. 선택 실행용 SQL의 기존 항목 ID를 유지해 이전 카탈로그와 별칭 충돌을 만들지 않도록 했다. 운영 DB에는 SQL을 실행하지 않았다.

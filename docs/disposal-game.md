# 60초 분리배출 랭킹 게임

- 경로: `#/game`, 상단 ‘게임’ 탭.
- 물건 이름과 재질·오염·포장 제거 상태를 읽고 4개 배출함 중 하나를 선택합니다.
- 60초 동안 계속 출제하며 선택하면 즉시 다음 문제로 넘어갑니다. 131개 상태별 문제에서 서로 다른 물건 최대 130개를 한 번씩만 출제합니다.
- 같은 물건의 깨끗한 상태·오염된 상태는 한 게임에 하나만 선택합니다. 준비된 물건을 모두 풀면 재출제하지 않고 종료합니다.
- `game-catalog.js`에서 기존 품목의 대표 명칭과 재질별 상태 설명을 재사용합니다. 별명을 다른 문제로 세지 않습니다.
- 정답 수가 많은 기록이 우선입니다. 동점이면 오답이 적은 기록, 먼저 등록한 기록 순으로 정렬합니다.
- 회원별 최고 기록 하나로 상위 20명을 표시합니다. 공개 이름은 중복될 수 있으며 계정 식별자로 사용하지 않습니다.
- 비회원은 연습할 수 있습니다. 연습 점수는 저장하거나 공동 랭킹에 올리지 않습니다.
- 게임 종료 시 푼 문제·정답·이유를 복습할 수 있습니다. 실제 분리배출 기록과 통계에는 포함하지 않습니다.

## 정답 효과와 난이도

- 정답을 실제 채점한 뒤 +1 표시, 작은 입자 효과, 성공 개수 강조를 표시합니다. 약 0.75초 후 정리되며 다음 문제 선택을 막지 않습니다.
- 연속 정답을 표시하지만 보너스 점수나 추가 시간을 주지 않습니다. 오답이면 연속 표시를 초기화합니다.
- 물건 그림과 선택지 그림이 일치해서 정답을 알 수 있던 힌트를 제거했습니다. 물건 이름의 앞쪽 재질 표현은 표시할 때만 줄이고, 판단에 필요한 재질·용도·오염 정보는 설명에 유지합니다.
- 종이팩·코팅 종이·감열지·인화지 설명은 정답 배출함을 바로 말하는 대신 물건의 특성과 현재 상태를 제시합니다.
- 연습 모드의 오답 선택지는 관련 재질 중심으로 구성합니다. 랭킹 모드는 서버가 발급한 4개 선택지를 그대로 사용합니다.
- 기존 문제 ID·판별 입력·정답·60초 제한·랭킹 집계는 유지하며 DB 수정은 필요하지 않습니다.
- 동작 줄이기 설정에서는 입자·확대 애니메이션 없이 정답 표시만 제공합니다. 효과 타이머는 재시작·페이지 이동 시 정리합니다.
- 전체 자동 테스트 101개가 통과했으며, 표시 이름 축약 후에도 서로 다른 물건이 같은 이름으로 보이지 않는지 게임 테스트로 재확인했습니다.
- 연습 모드에서 정답 효과·2연속 표시·오답 시 초기화를 확인했습니다. 운영 계정의 점수는 변경하지 않았습니다. 효과·난이도 수정의 운영 반영 여부는 Vercel 배포 상태와 배포된 코드로 확인합니다.

## 공동 랭킹과 보안

- `supabase/game-ranking.sql`은 기존 회원·배출 기록·RLS를 변경하지 않고 게임 전용 테이블과 RPC를 추가합니다.
- 기존 설치 환경은 `supabase/game-question-update.sql`을 실행합니다. 이전 세션·랭킹을 삭제하지 않고, 물건별 중복 없는 서버 출제를 추가합니다.
- 새 화면은 `start_disposal_game_v2`를 사용합니다. 업데이트 이전 화면에는 새로고침을 안내하여 모르는 문제 ID를 받아 오류가 나지 않도록 합니다.
- 사용자 확인에 따르면 SQL 실행을 완료했습니다. 실제 앱에서 공개 랭킹 RPC 조회가 성공하여 빈 랭킹 안내를 확인했습니다.
- 랭킹 도전은 로그인해야 합니다. 서버가 문제·선택지·마감 시간을 발급하고, 답변마다 서버 시간으로 마감을 검사하고 채점합니다.
- 클라이언트가 계산한 점수나 경과 시간을 랭킹에 제출하지 않습니다. 동일 답변 재전송은 중복 채점하지 않습니다.
- 사용자별 세션 접근을 확인하고 직접 테이블 읽기·쓰기를 금지합니다. 공개 RPC에는 이름·순위·정답·응답 수·등록 시각·본인 여부만 반환합니다. 이메일과 사용자 ID는 공개하지 않습니다.
- 공개 이름을 직접 입력하고 공개 동의에 체크한 뒤 등록합니다. 실제 계정 닉네임을 자동으로 게시하지 않습니다.
- 이 검증은 점수 직접 조작과 다른 계정 접근을 방지하는 기본 검증입니다. 자동 플레이 탐지·부정행위의 완전한 차단을 제공하지는 않습니다.

## 확인한 범위

- 배포 대상 게임 변경만 포함한 코드에서 자동 테스트 전체 91개 통과.
- 연습·서버 출제 모두 동일 물건·문제 중복이 없는지 확인하고, 같은 과자봉지의 상태별 문제가 한 판에 함께 등장하지 않는지 확인했습니다.
- 서버에서 준비된 130개 물건을 전부 풀었을 때 재출제하지 않고 종료·랭킹 등록이 되는 것도 로컬 PostgreSQL 호환 DB에서 검증했습니다.
- 문제 상태와 기존 판별 규칙의 일치를 검사한 것이며, 모든 실물 제품과 모든 지역의 배출 기준을 새로 검증한 것은 아닙니다.
- 실제 PostgreSQL 호환 로컬 DB에서 SQL 재실행, 문제 정답 일치, 권한, 서버 마감, 중복 채점, 계정 간 접근 차단, 최고 기록과 공개 필드를 확인했습니다.
- 브라우저에서 60초 연습 게임의 연속 출제, 정답·오답 집계, 시간 종료 후 정답 1개·오답 1개·정답률 50% 표시, 다시 도전, 비회원 로그인 안내를 확인했습니다.
- 이번 수정에서는 브라우저에서 35문제를 연속 진행해 동일 이름 중복 0개·선택지 4개·정답 9개·오답 26개·60초 후 종료를 확인했습니다.
- 응답 형식·문제 버전·선택지·서버 채점을 검증하며, 만료 후 통신 재시도 버튼이 타이머에 의해 계속 다시 생성되는 오류도 수정했습니다.
- 사용자 확인에 따르면 문제 업데이트 SQL 실행을 완료했습니다. 운영 환경에서 새 RPC가 존재하며 비회원 접근은 차단되는 것을 확인했습니다.
- 실제 Supabase 공개 랭킹 조회는 확인했습니다. 실제 로그인 계정으로 랭킹 게임을 끝내고 공개 기록을 등록하는 운영 환경 전체 흐름은 아직 수행하지 않았습니다.
- 기존 회원가입·로그인은 실제 계정으로 다시 수행하지 않았습니다. 기존 자동 테스트로 회귀를 확인했습니다.
- 새로고침·페이지 이동 시 진행 중인 화면은 초기화됩니다. 랭킹 세션의 서버 마감 시간은 계속 흐릅니다.
- 배포는 GitHub `main`과 연결된 Vercel 프로젝트를 사용합니다. 운영 반영 여부는 Vercel 배포 상태와 실제 배포된 코드를 확인합니다.

# 6회차: 전국 대형폐기물 신고 안내

대형폐기물 판별 결과의 신고 링크와 별도 ‘대형폐기물 신고’ 화면이 같은
지역 조회 함수를 사용한다. 이름·설명·사진으로 확인한 등록 안내와 저장
기록, 결과 복사에서도 결과의 배출 지역을 기준으로 안내한다.

전국 17개 시·도의 등록 지역 230곳을 연결한다. 현재 직접 신고 사이트
18곳, 지자체 대형폐기물 안내 페이지 76곳, 관할 공식 누리집 136곳이다.
직접 링크가 확인되지 않은 지역을 온라인 접수 가능 지역으로 표시하지
않는다. 공식 누리집에서 ‘대형폐기물’을 찾아 온라인·전화·방문 접수 중
운영하는 방법을 확인하도록 안내한다. 실제 신고나 결제는 외부 접수처에서
진행하며, 앱이 대신 접수하지 않는다.

시·군·구 이름은 시·도와 함께 조회한다. 시 소속 행정구는 관할 시로
연결하고, 세종은 구 선택 없이 조회한다. 미등록 지역 입력은 임의의 다른
지역 사이트 대신 지자체 찾기로 안내한다. 신고 안내는 수수료 자료의
유무와 관계없이 제공하고, 기존 지역별 수수료표는 유지한다.

# 분리배출 도우미 개선 우선순위

운영 버전 `6979f17`과 이번 상태 입력 변경을 기준으로 정리했다. 분리배출 안내는 **버리기 직전에 배출처와 첫 행동을 빨리 확인하는 것**을 우선한다. 나머지 기능은 다시 찾기, 일정 관리, 제보, 학습을 돕는 순서로 개선한다.

상태 선택은 이번 변경으로 처음부터 펼쳐진다. 깨끗한 물건의 빠른 선택 버튼은 유지한다. 아래 항목은 그다음에 할 일이다.

## 분리배출 방법 안내

| 순서 | 개선할 점 | 사용자에게 보여 줄 동작과 완료 기준 |
| --- | --- | --- |
| 1 | **이름을 몰라도 모양과 용도로 좁히기** | 분리배출 표시가 없는 경우 ‘음식이 담겼던 용기’, ‘겉포장 봉지’, ‘병이나 컵’처럼 물건을 보고 답할 수 있는 선택지를 제시한다. 예를 들어 ‘소스통’에서 유리병과 플라스틱 용기 중 같은 것을 선택하면 재질 질문을 되풀이하지 않는다. 모양이나 브랜드만으로 재질을 확정하지 않는다. |
| 2 | **오염이 남은 경우 답하기 쉽게 하기** | ‘제거할 수 있나요?’에 바로 답하기 어렵다면, 무엇을 확인하면 되는지 질문 바로 옆에서 알려 준다. 예를 들어 일반 종이는 ‘깨끗한 부분을 따로 남길 수 있나요?’, 용기는 ‘내용물을 비운 뒤 닦아낼 수 있나요?’로 묻는다. ‘아직 안 해봐서 모르겠어요’를 선택하면 먼저 할 일과 상태를 다시 고르는 버튼을 함께 보여 준다. |
| 3 | **사진에서 읽은 표시를 직접 판별로 연결하기** | 사진에서 `PP`만 읽혔다면 ‘본체에 적힌 표시가 맞나요?’부터 확인한다. 맞다고 답하면 해당 표시와 맞는 재질 선택을 열고, 용기인지 포장 비닐인지와 같은 남은 조건만 묻는다. 표시가 본체·뚜껑·라벨 중 어디에 있는지 불분명하면 사용자가 지정한다. 표시가 보인다는 이유만으로 배출 방법을 정하지 않는다. |
| 4 | **확인된 부속품과 아직 모르는 부속품을 분리해 안내하기** | 예를 들어 깨끗한 본체의 배출처는 바로 표시하고, 뚜껑에 재질 정보가 없으면 뚜껑 옆에 ‘재질 확인’ 버튼을 둔다. 실제로 떼어낼 수 있다고 확인한 경우에만 일부를 먼저 배출할 수 있다고 안내한다. 수정한 조건이 해당 부속품의 안내에 바로 반영되도록 한다. |
| 5 | **정보가 부족할 때 한 가지 다음 행동을 먼저 보여 주기** | ‘추가 확인 필요’만 반복하는 대신 ‘바닥에서 재질 표시 찾기’, ‘가스 용기는 관할 수거처에 문의하기’처럼 현재 결과가 막힌 이유에 맞는 행동을 맨 위에 둔다. 배출처와 준비가 확인된 품목은 ‘어디에’와 ‘먼저 무엇을’이 첫 화면에 함께 보이게 한다. |
| 6 | **지역 안내의 적용 범위와 문의처 명확히 하기** | 약·전지·깨진 유리·대형폐기물처럼 지역 차이가 큰 품목부터 수거 대상, 장소, 문의처를 보강한다. 공식 자료로 확인된 범위와 확인일을 표시하고, 건물마다 다른 수거 장소·시간은 단정하지 않는다. 지역이 설정되지 않은 결과에서 필요할 때만 지역을 고를 수 있게 한다. |
| 7 | **반복되는 미등록 이름을 사전에 반영하기** | 제보에서 반복되는 검색어를 우선 검토해 맞춤법 차이, 생활 속 표현, 제품 유형별 별칭을 추가한다. 같은 이름으로 여러 물건을 부르면 별칭 하나로 합치지 않고 후보로 보여 준다. 제보를 반영한 뒤에는 해당 이름으로 바로 찾을 수 있어야 한다. |

## 나머지 기능

| 순서 | 개선할 점 | 사용자에게 보여 줄 동작과 완료 기준 |
| --- | --- | --- |
| 1 | **함께 버릴 물건 목록 이어 쓰기** | 지금은 목록이 열린 세션에만 남고 배달 용기 묶음으로 시작한다. 어느 결과에서든 목록에 추가하고, 새로고침 후에도 품목별 확인 상태와 지역을 이어서 본다. 뚜껑을 본체 부속품으로도 적었을 때 중복을 찾아 정리할 수 있게 한다. |
| 2 | **최근 기록과 즐겨찾기에서 빠르게 다시 찾기** | 최근에 봤던 결과를 그대로 여는 동작과, 지난 조건을 불러와 오늘 물건을 다시 판별하는 동작을 나눈다. 자주 버리는 품목은 홈에서 위에 고정하고 순서를 바꿀 수 있게 한다. 기록에서 조건을 수정할 때 새 기록으로 남는지도 명확히 보여 준다. |
| 3 | **수거 요일 알림을 주소와 배출 유형에 맞추기** | 지금은 요일을 직접 지정해 기기에 저장하고 캘린더 파일을 받는다. 지역 또는 거주 방식이 달라졌을 때 어느 일정이 적용되는지 보여 주고, 기존 알림을 갱신하는 방법을 안내한다. 해당 주소에 적용되는 일정이 확인되지 않으면 사용자가 입력한 일정임을 표시한다. |
| 4 | **제보가 어디까지 처리됐는지 알려 주기** | 마이페이지의 상태 표시를 보완해 접수·검토·반영 여부와 처리 이유를 보여 준다. ‘같은 물건인지 확인할 사진이나 표시가 필요해요’처럼 보완 요청이 있으면 기존 제보에 이어서 제출할 수 있게 한다. 반영된 제보에서는 바뀐 안내로 바로 이동한다. |
| 5 | **시간 제한 없는 연습과 오답 복습 추가하기** | 60초 게임과 별도로 시간 제한 없이 고른 답의 이유를 바로 볼 수 있게 한다. 틀린 품목만 다시 풀거나 실제 분리배출 안내를 열 수 있게 하고, 연습 결과는 랭킹과 분리한다. |

다음 작업은 **이름 없는 물건의 후보 좁히기 → 오염 질문 개선 → 사진에서 읽은 표시 연결** 순서를 권한다. 세 작업 모두 검색을 포기하거나 같은 조건을 다시 입력하는 상황을 줄인다. 나머지 기능은 함께 버릴 물건 목록부터 손보면 실사용에서 바로 차이를 느낄 수 있다.

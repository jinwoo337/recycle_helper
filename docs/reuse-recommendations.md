# 6회차: 재사용 추천

분리배출 결과에 물건별 재사용 방법을 함께 표시한다. 이름으로 찾기,
사진·설명 모드의 확인된 등록 안내, 저장 기록 및 결과 복사에서 제공한다.

- 의류: 수선 후 사용, 세탁·건조 후 나눔
- 가구: 배치 변경·수납 용도, 사용 가능한 상태로 나눔
- 책: 나눔·중고 판매, 접수 여부 확인 후 기증
- 종이상자: 소품 정리함·택배 포장
- 유리병: 작은 물건 보관·꽃병
- 머그컵·도자기: 작은 도구 정리
- 침구: 세탁·건조 후 계속 사용, 수령 가능 여부 확인 후 나눔

기존 상태 질문에서 ‘깨끗하고 다시 쓸 수 있어요’를 선택한 경우 추천을
바로 표시한다. 청결만 확인되었거나 파손·기능 상태가 확인되지 않은
경우에는 ‘깨끗하고 파손 없이 쓸 수 있나요?’를 눌러 추천을 펼치게 한다.
청결을 사용 가능 상태로 자동 판단하지 않는다. 오염·손상 상태와 위험
품목에는 추천을 표시하지 않는다. 재사용 추천은 기존 배출 판정에 영향을
주지 않으며, 외부 AI 호출이나 별도 DB 변경 없이 동작한다.

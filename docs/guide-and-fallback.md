# 분리배출 안내와 미등록 품목 대응

확인일: 2026-10-27. 별도 배포·운영 DB 변경 없이 현재 앱 소스에서 동작합니다.

## 화면

- 홈의 마이페이지/내 지역 설정 바로가기를 `#/guide`의 분리배출 방법 안내로 교체했습니다. 계정 관리 메뉴는 상단에 유지합니다.
- 안내에는 네 가지 준비 단계, 8종 재질 카드, 약·건전지·음식물 검색 진입이 있습니다.
- 물품 입력에서 비회원도 지역을 선택합니다. 이 선택은 판별 입력·기록에 저장하며 계정 기본 지역은 바꾸지 않습니다.
- 확인된 배출 방식·준비 조건이 다르면 결과의 **다른 지역은 어떨까?** 버튼으로 비교합니다. 원래 결과와 기록은 유지합니다. 같은 방식의 지역은 묶고, 미확인 지역은 비교에서 제외합니다. 표현·출처만 다른 안내는 방식 차이로 세지 않습니다.

## AI 없는 판별 순서

1. 검토된 품목·별칭을 정확히 조회합니다. 약·전지·전자제품·조명 등은 재질보다 품목의 별도 수거 경로를 우선합니다. 운영 DB의 오래된 재질값이 이 경로를 가리지 않습니다.
2. 미등록 이름에는 물건 종류 질문을 표시합니다. 19개 종류 중 의약품·전지·손상 전지·조명·전자제품·압력 용기·화학제품·의류·침구·도자기·대형 생활용품 등은 종류별 안내를 사용합니다.
3. 재질 표시를 확인한 포장재나 음식물에는 재질·종류·오염·결합 상태 등 필요한 질문을 이어갑니다. 포장재를 선택했다고 바로 재활용으로 확정하지 않습니다.
4. 종류를 모르거나 정보가 모자라면 추가 확인 경로를 안내합니다. 서로 다른 위험 품목의 처리법을 한꺼번에 나열하지 않습니다.
5. AI 의견은 선택 기능이며 새 브라우저에서는 꺼져 있습니다. AI가 켜져도 직접 선택한 종류·검토된 품목 규칙이 우선하고 AI가 필수 답변을 자동으로 선택하지 않습니다. 기존에 켜 둔 선호는 유지합니다.

종류 선택은 사용자가 제공한 정보이며 물품 실물을 검증한 결과는 아닙니다. 임의의 이름만으로 모든 물건을 정확하게 분류할 수 있다고 보장하지 않습니다. 미등록 품목의 제보는 기존 제보 기능을 통해 검토 대기로 저장하며 검증 없이 카탈로그에 자동 등록하지 않습니다.

## 자료와 적용 범위

- 서울 25개 구: [서울시 공통 분리배출 안내](https://news.seoul.go.kr/env/archives/564022), [폐비닐 가이드라인](https://news.seoul.go.kr/env/archives/1895), [자치구별 수거 여건 확인 안내](https://news.seoul.go.kr/env/archives/558699), [음식물 RFID](https://news.seoul.go.kr/env/archives/74584). 서울시 공통 자료와 자치구별 검증을 구분해 표시합니다. 구청별 모든 품목·시간표를 검증한 것은 아닙니다.
- 대전 5개 구: 기존 `daejeon-guides.js`의 공식 구별 자료를 유지합니다. 구별 음식물 용기·스티로폼 색상·깨진 유리 등 확인된 차이를 비교합니다. 자세한 원문은 [지역 안내](regional-guide.md)를 참조합니다.
- 약: [서울시 폐의약품 수거 안내](https://news.seoul.go.kr/env/archives/564807). 포장 해체 방법은 지역마다 다를 수 있으므로 다른 지역에 서울 방식을 강제하지 않습니다. 모든 약국의 수거를 보장하지 않고 실제 수거처·접수 조건을 확인하도록 합니다.
- 별도 수거 품목은 대상·상태·접수처가 확인되지 않은 경우 `추가 확인 필요`를 유지합니다.

## 자동완성

일반 엔터와 한글 조합 확정 엔터에서 추천 목록을 닫습니다. 같은 입력의 뒤늦은 `compositionend`·`input`·focus 이벤트로 다시 열지 않으며, 이름을 바꾸거나 방향키로 탐색하면 다시 표시합니다. 폼 검증 실패·포커스 이탈·외부 클릭·결과 표시에서도 목록을 닫습니다. 화면을 떠날 때 이벤트와 미리 조회 타이머를 해제합니다.

## 검증

`tests/item-autocomplete.test.js`: 일반 엔터·IME 확정·후속 이벤트·방향키 선택·Esc·오류·정리 이벤트를 검증합니다. DOM 이벤트 대역을 사용하며 실제 Windows IME 조작을 재현한 테스트는 아닙니다.

`tests/guide-and-fallback.test.js`: 약·전지의 재질 없는 안내, 19종 수동 분류, AI와 종류 선택의 우선순위, 부족한 정보, 지역 30곳의 주요 품목, 비교 묶음·원본 보존·미확인 제외·오염 예외·DB의 오래된 품목값을 검증합니다. 기존 전체 테스트는 SQL/RLS·회원/비회원 기록·즐겨찾기·게임·7,680개 상태 조합을 포함합니다.

전체 자동 테스트 120개가 통과했습니다.

실제 브라우저 시각 검증은 도구가 현재 Windows 브라우저 URL을 확인하지 못해 중단됐습니다. 화면 배치와 실제 IME는 수동 검증이 남아 있습니다. UI 도구 차단을 우회하지 않았습니다.

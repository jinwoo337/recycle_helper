# 분리배출 백로그 반영 · 2026-11-13

기준 브랜치의 `e7ed2a9`에서 작업했다. 변경 사항은 로컬에 있으며 운영 사이트와 DB에는 적용하지 않았다.

| 항목 | 반영 사항 |
| --- | --- |
| 미등록 물건 | 홈과 이름 화면에서 종류 찾기·취소·다시 시도, 재질 표시, 설명·사진 전환, 등록 요청을 제공한다. 이름에서 받은 제안은 종류만 확인하거나 재질까지 확인할 수 있다. 설명·사진에서 받은 제안도 같은 조건 입력과 지역 규칙으로 이어진다. 미등록품의 생성된 배출 절차는 표시하지 않는다. |
| 확인한 조건 | PP·비닐·오염 등 명시한 사실을 확인란에 표시한다. 사진이나 문맥에서 추정한 조건은 확인란이 기본 선택되지 않는다. 라벨·뚜껑·필름은 별도 카드로 유지하며, 관찰된 부속품의 분리 가능 여부를 단정하지 않는다. 같은 검색의 화면 전환과 뒤로 가기는 답을 유지한다. |
| 결과와 공식 안내 | 결과 상단에 배출 방법과 다음 질문 또는 공식 이동 버튼을 표시한다. 서울·대전의 약, 부평·아산·노원의 전지, 김포 등 자료가 있는 지역의 깨진 유리, 대형폐기물 안내를 연결한다. 아산·노원에서 정상 전지는 주택 유형별 수거 안내를 제공한다. 공식 수거함의 위치·이용 시간 등이 없으면 시설이나 관할 담당 부서에 확인할 내용을 표시한다. |
| 함께 버릴 물건 | 배달 용기·뚜껑·필름을 목록에 담는다. 판별 결과는 재활용·종량제·전용 수거/재질별 배출·추가 확인으로 모으며, 미판별 물건도 목록과 복사에 남긴다. 이 목록은 같은 탭에서 유지되며 새로고침하면 비워진다. |
| 기록·제보 | 홈의 최근 기록·즐겨찾기에서 이전 조건을 불러올 수 있다. 설명·사진으로 받은 등록 기준 안내는 사용자가 선택할 때 결과만 기록한다. 미등록 제보에는 이름·지역·당시 결과가 첨부된다. 마이페이지에서 자기 제보 상태를 확인한다. |

공식 출처: [서울시 폐의약품](https://news.seoul.go.kr/env/archives/564807)·[수거함 지도](https://map.seoul.go.kr/smgis2/short/6OiGm), [부평구 폐전지](https://www.icbp.go.kr/main/life/clean/batteries.jsp), [아산시 폐전지 및 주택별 배출](https://www.asan.go.kr/main/cms/?no=588), [노원구 전지 수거](https://www.nowon.kr/www/minwon/minwon4/minwon4_03/minwon4_03_07.jsp), [김포시 깨진 유리](https://m.gimpo.go.kr/portal/contents.do?key=2723). 대형폐기물은 [대전 유성구](https://www.yuseong.go.kr/clean/html/sub03/0301.html), [아산시](https://www.asan.go.kr/main/cms/?no=566), [노원구](https://www.nowon.kr/www/minwon/minwon4/minwon4_03/minwon4_03_05/minwon4_03_05_01.jsp), [김포시](https://m.gimpo.go.kr/portal/contents.do?key=1437)의 공식 안내를 확인했다.

운영 Gemini의 기존 API에 개인정보 없는 미등록 PP 용기, 복합재질, 깨진 유리, 정상·손상 전지 설명을 보냈다. 다섯 사례 모두 응답을 받았다. 김포 깨진 유리 응답에는 일반 종량제 선택지가 섞였고, 복합재질 응답에는 지역 확인 없이 일반 배출을 제안한 문장이 있었다. 변경판은 Gemini에 식별과 관찰만 요청하고, 생성된 배출 지시를 버린다. 김포 백색마대 안내 또는 추가 확인으로 이어지는 경로를 로컬 테스트로 확인했다. **새 응답 형식은 아직 운영 Gemini에서 검증하지 않았다.**

운영 사진 API에는 실제 물건 대신 직접 만든 PP 표시 도안을 보냈다. 첫 요청은 일시적 혼잡으로 503을 반환했고, 재시도는 표시만 인식하고 배출 단계 없이 응답했다.

로컬 Chrome 모바일 크기에서 이름 분석 취소·재시도, 사진 오류 뒤 기존 사진 유지, 조건 전달·뒤로 가기, 라벨 질문 초점 이동, 묶음 복사, 주택별 안내를 확인했다. 합성 HEIC 파일을 실제로 JPEG 미리보기로 변환했다. 설명에서 저장한 깨진 유리 기록을 다시 열어 김포시 기준과 복사 출처를 확인했고, 즐겨찾기를 통해 재질·종류·지역을 불러왔다. 방향키·Enter와 한글 조합 Enter 처리를 모의 이벤트로 확인했다. iPhone 크기의 WebKit에서 화면 이동과 조건 전달을 확인했다. Chrome에서 홈·조건 확인·결과·묶음 화면을 axe로 검사했다. 제보는 모의 회원과 로컬 PostgreSQL 테스트에서만 확인했다.

출시 전에는 실제 iOS Safari와 Android Chrome에서 한글 키보드, 카메라, HEIC, 접근성 도구를 확인하고, 스테이징에서 새 Gemini 형식과 로그인 제보를 검증한다. 기존 운영 DB에 제보 상태와 공용 AI 종류 저장을 적용하는 절차는 [DB 설정 문서](database-setup.md)를 참고한다.

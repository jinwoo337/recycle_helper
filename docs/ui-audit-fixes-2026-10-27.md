# UI 점검 후 수정 내역

사용자 승인 후 2026-10-27에 수정했다. 운영 사이트 배포는 아직 하지 않았다.

| 점검 항목 | 수정 |
| --- | --- |
| UI-01 이전 약 기록의 전자제품 안내 | 원본 기록을 보존하면서 현재 규칙으로 표시·복사한다. 이전 AI 추정은 재사용하지 않는다. 부족한 조건은 재확인을 요청한다. |
| UI-02 보이지 않는 AI 스위치 | 일반 폼 스타일과 충돌하는 우선순위를 수정하고 트랙 크기를 명시했다. 브라우저에서 46×26px과 키보드 초점 스타일을 확인했다. |
| UI-03 종류·재질의 잘못된 조합 | 포장재와 음식물에 맞는 재질만 고르게 하고 판별 규칙에서도 같은 조합을 검증한다. |
| UI-04 서울 비닐의 모순된 결과 | 기름·물 자국 / 고형물 / 미확인 질문을 추가했다. 상태·방법·이유·부위별 지침을 함께 갱신한다. 답변은 기록과 즐겨찾기에 보존한다. |
| UI-05 공유할 수 없는 안내 링크 | `#/guide?material=vinyl` 형태로 변경했다. 직접 열기·새로고침·이전 `#guide-vinyl` 주소에서도 해당 카드로 이동한다. |
| UI-06 회원에게도 로그인을 요구하는 게임 문구 | 회원/비회원의 연습 종료 안내를 구분한다. |
| UX-07 지역 비교의 반복·과도한 길이 | 현재 결과는 방법만 표시하고 다른 지역은 차이 최대 두 항목을 요약한다. 전체 방법과 출처는 펼쳐 볼 수 있다. |
| UX-08 필터와 무관하게 남는 상세 기록 | 검색·필터·페이지에 없는 선택 기록의 상세 화면을 닫고 관련 이벤트도 해제한다. |

추가로 결과의 ‘다른 물건이에요’ 버튼에서 종류 선택 화면을 열 수 있게 했다.

## 검증

- 전체 `npm test`: 133개 통과. 이후 관련 테스트 24개 및 최종 회귀 테스트 7개 통과.
- `git diff --check`: 통과.
- 로컬 미리보기에서 실제 브라우저 이미지와 접근성 트리로 데스크톱 및 390×844 화면 확인.
- 스위치 표시, 포장재/음식물 선택 제한, 서울 비닐 질문과 결과, 지역 비교 펼치기, 안내 링크 직접 열기·새로고침, 필터 빈 결과와 상세 숨김 확인.
- 모바일 약·건전지 Enter 검색에서 자동완성 닫힘과 전용 안내, 깨진 유리 지역 비교, 가로 넘침 없음 확인.
- 브라우저 오류·경고 로그 없음.
- 운영 계정의 기존 기록·프로필·공개 랭킹은 변경하지 않았다. 로컬 비회원 기록만 생성했다.

회원 게임 종료 문구는 자동 테스트로 확인했다. 실제 한글 IME 조작, 실기기 모바일, 모든 물품의 지자체 현장 기준까지 검증한 것은 아니다.

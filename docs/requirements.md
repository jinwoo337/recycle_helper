# 서비스 요구사항

## 사용자가 계획한 기능

- 입력: 물건 이름, 주요 재질, 오염 여부, 세척 여부, 다른 재질과 결합 여부, 재질 분리 가능 여부.
- 출력: 최종 분리배출 방법, 필요한 처리 과정, 판단 이유.
- 화면: 로그인/회원가입, 메인, 상태 입력, 판별 결과, 나의 기록/통계.

## 검토 제안 — 아직 확정하지 않음

- 배출 지역 입력과 재질·상태의 ‘모르겠음’ 선택지.
- 현재 오염 상태와 제거 가능 여부 중심으로 세척 질문 정리.
- 답변에 따라 관련 질문만 표시.
- 결과에 근거 출처, 기준일, 적용 지역과 입력 수정 기능 제공.
- 정보 부족 또는 미지원 품목에 대한 추가 확인 안내.
- 비회원 판별 허용 여부와 기록·통계의 구현 우선순위.
- 인증 도입 시 비밀번호 재설정, 계정 관리 및 회원 탈퇴 흐름.
- 잘못된 결과 신고 기능.

## 구현 전 결정할 사항

- 프런트엔드·백엔드 기술 스택과 데이터 저장 방식.
- 지원 지역 및 품목 범위.
- 판별 기준의 출처와 갱신 방식.
- 회원 기능 및 기록 저장 범위.

## 2회차 진행 현황

프런트엔드는 HTML/CSS/JavaScript로 구현합니다. 기존 폴더 구조를 유지하면서 메인·로그인·회원가입 화면, 공통 레이아웃, 반응형 스타일, 화면 이동과 기본 입력 검증을 구현했습니다. 인증 화면은 UI 체험용이며 실제 회원가입, 로그인, 정보 저장은 수행하지 않습니다. 비밀번호 8자 이상 등의 검증은 현재 화면 기준이며 서버 인증 정책은 추후 결정합니다.

후속 구현으로 공개 테스트 회원의 이메일·비밀번호를 비교하는 모의 로그인을 추가했습니다. 일치하면 메인 화면으로 이동하고, 불일치하면 오류를 안내합니다. 테스트 회원 ID만 sessionStorage에 보관해 같은 탭에서 상태를 유지하며 로그아웃을 지원합니다. 실제 서버 인증이나 회원가입 저장은 수행하지 않습니다.

물건·상태 입력, 판별 결과, 기록·통계 및 서버 연동은 아직 구현하지 않았습니다. 상단의 검토 제안은 별도 확정 전까지 구현 요구사항으로 간주하지 않습니다.

회원가입·로그인 연동 수정: 가입 정보를 localStorage에 저장하고 모의 로그인에서 조회합니다. 비밀번호 원문 대신 salt와 PBKDF2 검증값을 저장하며 중복 이메일 및 저장 실패를 안내합니다. 가입 완료 후 로그인 화면으로 이동하고 가입한 닉네임을 표시합니다. 이전의 입력 확인 전용 회원가입을 대체합니다.

물건·상태 입력 화면 추가: 메인의 분리배출 알아보기 버튼에서 이동합니다. 물건 이름, 주요 재질, 오염·세척·결합 여부를 입력하며, 결합된 경우에만 분리 가능 여부를 질문합니다. 입력 내용을 요약하고 수정할 수 있습니다. 현재는 배출 방법을 판별하지 않습니다.

최근 물품 목록 추가: 물건 입력을 확인할 때 이름만 브라우저에 저장해 오른쪽에 최근 8개를 표시합니다. 같은 이름은 최신 위치로 이동하고 회원별·비회원별 기록을 분리합니다. 상태 정보나 판별 결과는 저장하지 않으며, 목록은 실제 배출 완료를 뜻하지 않습니다.

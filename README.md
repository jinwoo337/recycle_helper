# 맞춤형 분리배출 도우미

물건과 상태를 입력하면 최종 분리배출 방법, 필요한 처리 과정, 판단 이유를 안내하는 웹서비스.

현재는 프로젝트 폴더 구조만 준비한 상태입니다. 화면, 라우팅, 판별 로직, 인증, API, 데이터베이스는 구현하지 않았습니다. 기술 스택과 실행 환경도 아직 지정하지 않아 설치·실행 명령은 없습니다.

## 프로젝트 구조

```text
recycling-helper/
├── docs/                  # 요구사항과 향후 설계 문서
├── public/
│   ├── images/            # 정적 이미지
│   └── icons/             # 정적 아이콘
└── src/
    ├── pages/
    │   ├── login/         # 로그인
    │   ├── signup/        # 회원가입
    │   ├── main/          # 메인
    │   ├── item-input/    # 물건 및 상태 입력
    │   ├── result/        # 판별 결과
    │   ├── history/       # 나의 기록
    │   └── statistics/    # 나의 통계
    ├── components/        # 여러 화면에서 사용하는 UI
    ├── layouts/           # 공통 화면 틀
    ├── styles/            # 공통 스타일
    ├── services/          # 외부 API 및 데이터 접근
    ├── domain/
    │   └── disposal/      # 분리배출 판단 규칙과 처리 과정
    ├── types/             # 공통 데이터 구조
    └── utils/             # 범용 보조 함수
```

빈 폴더의 `.gitkeep`은 Git에 폴더를 보존하기 위한 파일입니다. 실제 코드를 추가할 때 제거해도 됩니다.

화면 폴더는 역할을 구분하기 위한 구조이며 URL이나 프레임워크의 라우팅 규칙을 확정하지 않습니다. 기록과 통계는 필요하면 하나의 화면으로 묶을 수 있습니다. 백엔드와 데이터베이스 구조는 기술 스택 결정 후 추가합니다.

서비스 범위와 검토 사항은 [요구사항](docs/requirements.md)에 정리했습니다.
